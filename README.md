# 🐳 Docker Hands-On Lab

A hands-on project covering Docker fundamentals, container
management, networking, persistent storage, Dockerfile, and
Docker Compose.

## 🚀 Topics Covered

- Docker Images & Containers
- Container Lifecycle Management
- Docker Hub
- Docker Networking
- Port Mapping
- Docker Volumes
- Bind Mounts
- Dockerfile
- Custom Docker Images
- Docker Compose
- Multi-container Applications
